## Layout inspection

Pencil layout-problem inspection was run for every mapped full frame. The only reported issues were pre-existing clipped notification badges under sidebar nodes `K0ZOE/m7pGK` and `h0hDg/m7pGK`; they are outside this feature’s implementation surfaces and are excluded from acceptance. No mapped card or tracking node reported an intrinsic layout problem.

At the required `390 × 844` viewport there is no authoritative Pencil frame. The accepted responsive contract is to stack header metadata, metrics, document cards and signatory rows; keep tabs, progress and available route actions visible; wrap button groups; preserve a minimum 44px touch target; and introduce no horizontal page overflow. The main Formalization page stacks its contracting action below the content cards. Tables/definition lists must become labeled vertical rows, not horizontally scrolling desktop replicas.
