Todos os seis nós foram inspecionados visualmente. A inspeção de layout não encontrou problemas nos diálogos; os quadros semanal/mensal registram apenas um badge compartilhado parcialmente cortado, que não deve ser reproduzido. Os PNGs exportados são imagens válidas e não vazias; as instâncias de dois modais cresceram 1 px em cada eixo no export.
